# Simple Salary Prediction GUI

This is a simple Python application that predicts **Salary** based on **Years of Experience** using Linear Regression.  
It provides an easy-to-use **Graphical User Interface (GUI)** built with **Tkinter** and uses **Matplotlib** for visualization.

---

## Features
- 📂 Load `Salary_Data.csv` file.
- 📊 Display scatter plot of Salary vs. Years of Experience.
- 🧠 Train a Linear Regression model (using scikit-learn).
- 📈 Show evaluation metrics:
  - MSE (Mean Squared Error)  
  - RMSE (Root Mean Squared Error)  
  - R² (Coefficient of Determination)
- 📉 Visualize training data, test data, and the regression line.
